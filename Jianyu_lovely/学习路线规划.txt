3.1 RAG (检索增强生成) (2周)

学习内容:
- RAG 原理
  * 文档处理流程
  * 向量检索原理
  * 上下文构建
  
  RAG 完整流程:
  # 1. 加载文档
  documents = loader.load(file_path)
  
  # 2. 分割文本
  chunks = text_splitter.split_documents(documents)
  
  # 3. 向量化
  embeddings = embedding_model.embed_documents([doc.page_content for doc in chunks])
  
  # 4. 存储到向量库
  vector_store.add_documents(chunks)
  
  # 5. 检索
  retrieved_docs = vector_store.similarity_search(query, k=4)
  
  # 6. 构建提示词
  context = "\n".join([doc.page_content for doc in retrieved_docs])
  prompt = f"Context: {context}\n\nQuestion: {query}"
  
  # 7. 生成回答
  answer = llm.chat(prompt)

- 向量数据库
  * FAISS（本地向量库）
  * ChromaDB（轻量级向量库）
  * Milvus（分布式向量库）
  * Elasticsearch（搜索引擎）
  
  项目中的应用:
  from langchain.vectorstores import FAISS, Chroma
  
  # FAISS
  faiss_store = FAISS.from_documents(chunks, embeddings)
  
  # ChromaDB
  chroma_store = Chroma.from_documents(
      chunks, 
      embeddings,
      collection_name="my_kb"
  )

- 文本分割策略
  * 递归字符分割
  * 中文文本分割
  * 语义分割
  
  项目中的应用:
  from chatchat.server.file_rag.text_splitter import ChineseTextSplitter
  
  splitter = ChineseTextSplitter(
      chunk_size=500,
      chunk_overlap=50
  )

实践任务:
- 从零构建一个 RAG 系统
- 对比不同向量数据库的性能
- 优化文本分割策略

学习资源:
- RAG 原理解析: https://www.anthropic.com/index/retrieval-augmented-generation
- 向量数据库对比: https://zilliz.com/learn/what-is-vector-database


3.2 Agent 系统 (2周)

学习内容:
- Agent 原理
  * ReAct 模式（推理+行动）
  * 工具调用机制
  * 思维链 (Chain of Thought)
  
  项目中的应用:
  from langchain.agents import AgentExecutor, create_react_agent
  
  tools = [search_tool, calculator_tool]
  agent = create_react_agent(llm, tools, prompt)
  agent_executor = AgentExecutor(agent=agent, tools=tools)
  result = agent_executor.invoke({"input": "查询今天天气"})

- 工具开发
  * 工具定义
  * 工具注册
  * 工具调用
  
  项目中的应用:
  from langchain.agents import tool
  from chatchat.server.pydantic_v1 import Field
  
  @regist_tool(title="数据库对话")
  def text2sql(
      query: str = Field(description="自然语言查询")
  ):
      """与数据库对话的工具"""
      result = query_database(query, config)
      return result

- Agent 类型
  * ReAct Agent
  * Structured Chat Agent
  * OpenAI Functions Agent
  
  项目中的应用:
  from langchain.agents import create_structured_chat_agent
  
  agent = create_structured_chat_agent(
      llm=llm,
      tools=tools,
      prompt=prompt
  )

实践任务:
- 开发自定义 Agent 工具

- 对比不同 Agent 类型的效果
